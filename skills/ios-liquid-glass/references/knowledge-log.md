Record date, context, mechanism, correction and evidence. Generalize from projects; do not copy personal data into this file.

## 2026-11-11 — Functional hierarchy

A running analytics UI became clearer when data surfaces stayed calm while navigation, toolbar groups and popovers shared material tokens. A full-width empty toolbar and a full-width enclosure around two legend toggles added noise rather than useful depth. Compact controls preserved their semantics and reduced competing outlines. Verified in Chromium desktop and a 390px iframe, not physical iPhone Safari.

## 2026-11-11 — Indicators and metrics

A composite performance index and a cumulative XP level are different constructs. Name them separately, preserve formulas, explain baseline and time window, and avoid optimistic chart titles that contradict the data. Conditional comparisons need actual previous data; a missing baseline is not zero improvement.

## 2026-11-11 — Optical source and platform limits

CSS/SVG backdrop displacement can process real backdrop detail on a verified supported engine. A WebGL renderer needs an explicit texture source; reconstructing DOM is not direct access to browser pixels. Smooth lens movement does not prove source freshness or hardware GPU speed. Keep Safari fallback and physical-device status explicit.

## 2026-11-11 — Fixed navigation

Filtering a mobile shell can relocate a fixed descendant dock. Check ancestor compositing and dock bounds before rewriting the drag controller. Removing duplicate foreground icons and mask dependencies prevents a class of disappearance bugs; cross-browser validation remains necessary.

## 2026-11-11 — Locally resolved compound material tokens

A compound custom property inherited from the theme can resolve references in its defining scope. Overriding only a child's opacity token may therefore leave the inherited background unchanged. Resolve the compound surface expression on the actual material element; test computed opacity and visible settings changes. This is an implementation finding from shared clear/regular/transient web profiles, not a native Apple rule.

## 2026-11-11 — Selection-first comparison

A comparison page can feel complete before a graph exists by presenting actual records with useful metrics and explicit selection states. After the second selection, compact the picker to selected records and keep an obvious edit-selection action. Preserve independent toggles and a count; avoid invented preview data or a giant empty stage. Check deselection, reset, keyboard operation and mobile overflow.
