# Runflow Analytics

Запустите `npm run demo` и откройте `/examples/runflow-pulse/index.html`.

| Элемент | Где искать | Поведение |
| --- | --- | --- |
| Последняя пробежка | `.latest-run`, `showWorkout` | Дистанция, время и темп последней записи. «Подробнее» открывает тот же диалог, что журнал. |
| Панель и карточка метрики | `.an-panel`, `.metric` | Подпись, значение, единица и пояснение в стабильной сетке |
| Фильтр периода | `mountGlassSegmentedControl` | 7, 30 и 90 дней с общей подложкой и клавиатурным выбором |
| График стабильности | `drawChart`, `.chart-point` | Наведение, нажатие и стрелки открывают значение CV за отрезок |
| Распределение темпа | `drawZones`, `.zone-list` | Общая шкала и подписи с долями дистанции |
| Журнал | `drawJournal`, `.workout-row` | Раскрытие списка и диалог с деталями, закрываемый клавишей Escape |

Данные заданы в `dashboard.js`. Все блоки используют одно окно дат. График рисуется из данных SVG, а метки и фокус управляются HTML-кнопками. При снижении движения смена периода происходит без перехода графика. При переносе панели используйте её семантическую разметку и адаптируйте локальные токены в `analytics.css` под тему проекта.

## Правила для следующих экранов

- Начинать с соответствующего экрана Runflow. Сохранять его задачу, главный показатель, тему и компоненты навигации. Из референса заимствовать конкретный приём и проверять его в контексте.
- Держать один главный блок в первом экране. Дополнительные метрики объединять в сводку с простыми разделителями. Сравнивать крупный и узкий кадры с исходным экраном.
- Сохранять монохромную основу Runflow. Размещать стекло там, где оно связано с управлением. У каждой оптической поверхности один слой материала, у индикатора отдельная геометрия.
- Переиспользовать контроллеры сегмента и Dock. Проверять выбор после отпускания, быстрое перенаправление, отмену и прокрутку под Dock. Публикация мобильной компоновки и подтверждение движения на iPhone требуют отдельных проверок.

- Заголовки называют разделы. Подписи объясняют единицы, интервал, статус или действие. Удалять слоганы, дублирующие даты и пояснения, которые пересказывают метрику. Использовать одну работающую кнопку для деталей пробежки.

- На обзоре давать последний записанный результат до сводки и графика. Сохранять в интерфейсе только названия действий, состояния, данные, единицы измерения и пояснения, необходимые для решения. Проверять дубли между соседними заголовками, легендами и метаданными.

- Для сегментов и Dock использовать общий контроллер. Подложка должна отступать от края трека, кнопки остаются прозрачными при нажатии. Капсула реагирует на скорость движения, а выбор применяется при отпускании. Смена раздела запускает отдельный короткий переход содержимого с учётом reduced motion.
