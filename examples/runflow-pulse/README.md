# Runflow Analytics

Запустите `npm run demo` и откройте `/examples/runflow-pulse/index.html`.

| Элемент | Где искать | Поведение |
| --- | --- | --- |
| Панель и карточка метрики | `.an-panel`, `.metric` | Подпись, значение, единица и пояснение в стабильной сетке |
| Фильтр периода | `mountGlassSegmentedControl` | 7, 30 и 90 дней с общей подложкой и клавиатурным выбором |
| График объёма | `drawChart`, `.chart-point` | Наведение, нажатие и стрелки открывают значение отрезка |
| Распределение темпа | `drawZones`, `.zone-list` | Общая шкала и подписи с долями дистанции |
| Журнал | `drawJournal`, `.workout-row` | Раскрытие списка и диалог с деталями, закрываемый клавишей Escape |

Данные заданы в `dashboard.js`. Все блоки используют одно окно дат. График рисуется из данных SVG, а метки и фокус управляются HTML-кнопками. При снижении движения смена периода происходит без перехода графика. При переносе панели используйте её семантическую разметку и адаптируйте локальные токены в `analytics.css` под тему проекта.
