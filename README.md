# iOS Liquid Glass

Переиспользуемый Agent Skill для разработки и аудита Liquid Glass UI: сайты, React-приложения, дашборды и мобильный веб. Включает накопленный опыт Runflow без кода приложения и пользовательских данных.

## Установка в Codex

Склонируйте репозиторий и скопируйте папку `skills/ios-liquid-glass` в ваш каталог `~/.codex/skills/`. В Windows используйте `%USERPROFILE%\.codex\skills\`. Файл `SKILL.md` должен лежать непосредственно внутри папки `ios-liquid-glass`.

Вызов: `$ios-liquid-glass`.

Пример: «Используй $ios-liquid-glass. Изучи существующий интерфейс, составь карту компонентов и улучши материалы и движение, сохранив функции и данные. Проверь результат на desktop и mobile и укажи ограничения Safari».

## Содержимое

- [SKILL.md](skills/ios-liquid-glass/SKILL.md): рабочий процесс и обязательные ограничения.
- `references/`: слои, материалы, физика движения, рендеринг, терминология, типовые ошибки и критерии приёмки.
- `references/knowledge-log.md`: проверенные выводы и оставшиеся неопределённости.
- `assets/material-tokens.css`: стартовые токены материалов.
- `assets/core/`: генератор карты преломления и совместимость.
- `scripts/`: генерация и численные регрессионные проверки.

## Основные принципы

Стекло прежде всего у навигации, плавающих контролов и меню. Контент, таблицы и графики остаются читаемыми. Форма, оптика, блики и физика движения образуют согласованный материал. Не подменяйте рефракцию размытием и не выдавайте реконструированную текстуру за прямое чтение DOM.

Clear и Regular — варианты материала Apple; Transient в этом скилле — профиль проекта для временных поверхностей, а не официальное третье название Apple.

Chromium-эффект не доказывает совместимость с Safari. Физическая проверка iPhone остаётся отдельным этапом. Скилл не является нативной реализацией Apple и не гарантирует идентичность iOS.

## Накопление опыта

После существенной итерации добавляйте в `references/knowledge-log.md` обобщённый вывод: наблюдение, механизм, исправление, среда проверки, доказательство и оставшиеся ограничения. Удаляйте опровергнутые рекомендации и дубликаты. Не сохраняйте личные записи, секреты и данные аккаунтов.

Обновление выполняется явным изменением файлов и коммитом. Подключение GitHub само по себе не создаёт автоматическую синхронизацию с установленным скиллом ChatGPT; обновляйте обе копии осознанно.
